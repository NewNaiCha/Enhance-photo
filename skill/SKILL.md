# 技能修图

使用这个 skill，先判断图片属于什么拍摄题材，再套用合适的摄影参数和对应的重建/增强提示词。对于人像，还要优先保持人物身份和场景连续性。

## 工作流

1. 先检查参考图。
2. 先做题材分类，从下面类别里选择最贴近的一类：
   - 晴天室外人像
   - 阴天人像
   - 傍晚日落人像
   - 室内窗边人像
   - 夜景人像手持
   - 风景白天
   - 日出日落风景
   - 夜景建筑 / 车轨
   - 街拍 / 纪实
   - 美食 / 静物
   - 多人合影
   - 小孩 / 宠物
   - 运动 / 比赛
3. 再识别当前图像的关键视觉信息：
   - 主体类型：单人、多人、景物、建筑、食物、宠物、运动主体
   - 构图距离：特写、头像、半身、全身、广角大场景、近距离静物
   - 机位关系：平视、轻微俯拍、轻微仰拍、低机位、高机位
   - 光线类型：硬光、柔光、窗边光、阴天光、逆光、混合光、夜景环境光
   - 背景类型：自然环境、街道、室内、纯色背景、建筑群、桌面、活动现场
   - 动作状态：静态、轻微动作、高速运动
4. 根据题材匹配镜头和参数，使用 [references/scene-parameters.md](references/scene-parameters.md)。
5. 如果分类结果是“人像类”，除非用户明确允许，否则必须保持这些不变量：
   - 同一个人物身份
   - 相同面部几何结构
   - 相同表情
   - 相近头部朝向和姿态范围
   - 相同发型和主要修饰特征
   - 若只是清理瑕疵，则保持相同服装轮廓
   - 相同背景和布局
6. 如果用户明确要求“85mm 人像重建模式”，套用固定拍摄意图：
   - 镜头：85mm
   - 光圈：f/1.4
   - 曝光倾向：+1.6 EV 的提亮观感
   - ISO：100
   - 快门：1/200
7. 让固定参数与原场景协调：
   - 如果原场景明显不符合 ISO100 和 1/200 的真实手持拍摄条件，仍然保留用户指定参数，但把结果描述为“按这些参数受控重建同一张图”，而不是声称原图本来就是这样拍的。
   - 即使参数是理想化重建，也必须保持视觉场景不变。
8. 如果用户没有指定固定参数，就优先采用题材对应的推荐参数，而不是强行套 85mm 人像参数。
9. 如果用户要直接改图，在写好提示词后调用 `imagegen` 相关能力。

## 题材路由规则

按下面规则选择模板：
- 单人或双人，强调脸部、情绪、皮肤和虚化时，优先进入“人像类”
- 画面主体是大场景、山水、城市天际线或日落天空时，进入“风景类”
- 画面主体是建筑夜景、灯轨、桥梁、城市夜色时，进入“夜景建筑 / 车轨”
- 画面重点是人物与环境关系、抓拍瞬间、街头纪实时，进入“街拍 / 纪实”
- 画面重点是菜品、摆盘、器皿、桌面陈列时，进入“美食 / 静物”
- 明显是多人同框，且需要前后排都清楚时，进入“多人合影”
- 主体是孩子、宠物，或者动作轻快不稳定时，进入“小孩 / 宠物”
- 主体高速移动，或存在比赛、跑步、球类、舞台抓拍时，进入“运动 / 比赛”

## 编辑规则

始终把“题材正确”和“场景保真”放在前面。遇到人像时，再把“身份保真”放在“美化”之前。

允许的改动：
- 轻微皮肤清理
- 轻微临时瑕疵清理
- 轻微降噪
- 温和的明暗与色调平衡
- 轻微锐化和微对比增强

除非用户明确要求，否则禁止：
- 在非人像场景里，随意改动主体类型
- 在非人像场景里，乱切换题材对应的镜头语言
- 替换、简化、扩展或移动背景
- 添加物体、道具、光斑、雾气或装饰元素
- 改构图和主体布局位置

如果是人像类，额外禁止：
- 改表情
- 改脸型或骨相
- 改眼睛大小、鼻形、唇形、下颌线或影响身份识别的肤色特征
- 改发型设计、年龄感、族裔特征或体型
- 替换服装或重做服装风格

## 输出格式

输出三部分。

### 1. 场景分析

用 3 到 6 行概括：
- 识别出的题材类别
- 主体和构图距离
- 大致光线类型和方向
- 背景类型
- 推荐镜头和参数
- 如果用户要求 85mm 固定重建，说明它是否可直接成立，还是应视为“受控重建”

### 2. 参数建议

按题材输出：
- 镜头
- 光圈
- 快门
- ISO
- 为什么这样选

### 3. 最终提示词

根据题材选择模板：
- 人像类使用 [references/prompt-template.md](references/prompt-template.md)
- 其他题材使用 [references/non-portrait-template.md](references/non-portrait-template.md)

把所有方括号字段替换成当前图片的具体信息。
约束语言要明确，不要模糊表述。

## 默认提示策略

构造最终提示词时，把参考图的环境外观视为必须严格保留。身份、表情、面部几何结构和背景连续性都是硬约束。优先使用“重建这同一张图”的表述，不要使用“参考”“类似”“受启发于”这种弱约束说法。

## 失败场景

遇到以下情况，先说明缺失点，不要直接改图：
- 面部被严重遮挡
- 参考图分辨率太低，无法可靠保留身份
- 图中有多张脸，目标人物不明确
- 用户提出互相冲突的要求，比如“脸完全不变”同时又“改表情”
- 图像题材判断存在明显歧义，比如既像环境人像又像街拍纪实，这时要说明你最终采用了哪个分支
