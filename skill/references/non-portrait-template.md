# 非人像提示词模板

当识别结果不是“以单人人像身份保真”为主时，使用这个模板。

## 通用模板

基于这张参考图片进行增强并重建，且必须把参考图作为唯一真实依据。保持原图的题材、主体类型、构图关系、透视、机位、背景结构、空间层次和光线氛围不变。允许轻微清理噪点、轻微优化明暗层次、轻微提升清晰度与色彩纯净度，但不得改变场景内容本身。

使用 [镜头]、[光圈]、[快门]、[ISO] 的拍摄意图重新创建这张图像。保持与参考图完全相同的主体布局、背景位置、透视方向、裁切比例和环境外观。保留 [光线描述]、[背景描述]、[主体描述]、[构图描述]。

负面约束：不要新增物体，不要删除物体，不要移动主体，不要改变背景结构，不要替换环境，不要改变题材属性，不要引入新的风格化特效，不要改变画面叙事重点。

## 分类补充规则

- 风景类：强调山体、天空、云层、水面、建筑轮廓位置不变
- 夜景建筑 / 车轨：强调建筑结构、灯光轨迹方向、桥梁和道路关系不变
- 街拍 / 纪实：强调人物与环境关系、抓拍瞬间、街头真实感不变
- 美食 / 静物：强调摆盘、器皿、桌面元素、光源方向不变
- 多人合影：强调人数、站位、前后排关系、构图中心不变
- 小孩 / 宠物：强调动作瞬间、主体神态、环境关系不变
- 运动 / 比赛：强调运动姿态、比赛动作、机位角度和主体方向不变
