# 场景参数速查

按识别出的题材类别匹配镜头和参数。

## 1. 晴天室外人像

- 镜头：50mm / 85mm
- 参数：f1.4-f2.8，1/500-1/2000，ISO100
- 适合：写真、半身、特写、草地、公园、街头
- 提醒：中午太阳太硬，优先找树荫、墙边阴影、逆光

## 2. 阴天人像

- 镜头：50mm / 85mm
- 参数：f1.4-f2.2，1/200-1/500，ISO100-400
- 适合：最省心的人像天，皮肤好看，光线柔
- 提醒：阴天是人像最好练手的天气

## 3. 傍晚日落人像

- 镜头：35mm / 50mm / 85mm
- 参数：f1.4-f2.8，1/200-1/800，ISO100-400
- 适合：逆光氛围、轮廓光、情绪感照片
- 提醒：脸黑就加曝光补偿，或者让人物转向侧光

## 4. 室内窗边人像

- 镜头：50mm / 85mm
- 参数：f1.4-f2，1/160-1/250，ISO200-800
- 适合：安静、干净、有质感的人像
- 提醒：人靠近窗，脸朝窗户 30 到 45 度最好看

## 5. 夜景人像手持

- 镜头：35mm / 50mm / 85mm
- 参数：f1.4-f2，1/160-1/250，ISO800-3200
- 适合：路灯、商场、霓虹、街头夜拍
- 提醒：夜里先保快门，宁可 ISO 高一点，也别拍糊

## 6. 风景白天

- 镜头：16-35mm / 24mm / 35mm
- 参数：f8-f11，1/100-1/500，ISO100
- 适合：山水、城市天际线、旅行照
- 提醒：风景一般不追求大虚化，重在层次和清晰度

## 7. 日出日落风景

- 镜头：16-35mm / 24-70mm
- 参数：f8-f11，1/30-1/250，ISO100
- 适合：天空颜色丰富、层次强的时候
- 提醒：快门慢了就上三脚架

## 8. 夜景建筑 / 车轨

- 镜头：16-35mm / 24mm
- 参数：f8-f11，1s-20s，ISO100
- 适合：城市夜景、桥梁、车流、灯轨
- 提醒：必须三脚架，手持基本不行

## 9. 街拍 / 纪实

- 镜头：35mm / 50mm
- 参数：f2.8-f5.6，1/250-1/1000，ISO100-800
- 适合：抓瞬间、拍环境和人物关系
- 提醒：街拍优先快门，别太追求大光圈

## 10. 美食 / 静物

- 镜头：35mm / 50mm / 85mm / 微距
- 参数：f2.8-f5.6，1/60-1/200，ISO100-800
- 适合：餐厅、甜品、桌面、产品
- 提醒：窗边侧光最好，顶灯容易脏

## 11. 多人合影

- 镜头：24mm / 35mm
- 参数：f4-f8，1/125-1/250，ISO100-800
- 适合：朋友聚会、家庭照、毕业照
- 提醒：别开太大光圈，不然前后排容易虚

## 12. 小孩 / 宠物

- 镜头：50mm / 85mm / 70-200mm
- 参数：f1.8-f4，1/500-1/2000，ISO200-3200
- 适合：跑动、玩耍、抓表情
- 提醒：这种题材快门第一

## 13. 运动 / 比赛

- 镜头：70-200mm / 100-400mm
- 参数：f2.8-f5.6，1/1000-1/2000，ISO400-6400
- 适合：球类、跑步、演出抓拍
- 提醒：对焦模式和连拍也很重要

## 镜头选择参考

- 16-35mm：风景、建筑、旅行大场景、室内
- 24mm：环境人像、建筑、旅行
- 35mm：街拍、纪实、环境人像，最万能
- 50mm：半身人像、静物、日常，比较均衡
- 85mm：特写、半身人像、压缩感强、背景虚化漂亮
- 70-200mm：舞台、运动、人像、远距离抓拍
- 微距：花、昆虫、首饰、细节

## 通用改参数口诀

- 人不动：快门至少 1/125
- 人轻微动作：至少 1/200
- 小孩宠物跑动：至少 1/500
- 运动：至少 1/1000
- 想虚化强：开大光圈 f1.4-f2
- 想大家都清楚：收一点 f4-f8
- 光线不够：先看能不能降快门，不能降就加 ISO

## 新手最稳的 3 组万能参数

- 白天人像：85mm f2 1/500 ISO100
- 阴天 / 窗边人像：85mm f1.8 1/200 ISO400
- 夜景人像：35mm 或 50mm f1.8 1/200 ISO1600
