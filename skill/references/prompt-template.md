# 提示词模板

当用户希望基于参考图做“严格保身份的人像增强 / 重建”时，使用这个模板。

## 直接编辑模板

基于这张参考人像图进行增强并重建，且必须把参考图作为唯一真实依据。通过精确保留面部几何结构、维持原表情、维持原脸型、保留所有关键身份特征，来高保真保留人物身份。仅允许轻微清理临时性皮肤瑕疵、轻微噪点和轻微色调问题。不得改变年龄感、族裔特征、发型设计、妆容身份特征、体型、服装结构或姿态。

背景必须与参考图完全一致。禁止替换，禁止修改，禁止新增物体，禁止删除物体，禁止布局偏移，禁止改变机位，禁止重设计环境。环境在结构、位置和视觉外观上都必须与参考图完全相同。

使用 85mm 镜头、f/1.4 光圈、ISO 100、1/200 快门速度，并带有 +1.6 EV 提亮观感，重新创建这张图像。保持与参考图完全相同的构图、透视、裁切、机位高度，以及人物与背景之间的空间关系。保留 [光线描述]、[背景描述]、[姿态/构图描述]。

负面约束：不要改变表情，不要改变面部比例，不要重塑眼睛、鼻子、嘴唇、下颌、脸颊或下巴，不要把人物修成另一个人，不要改变发型轮廓，不要替换服装，不要添加电影化特效，不要移动或替换背景中的任何内容。

## 场景化填写项

使用前把这些字段替换为具体内容：
- [光线描述]：例如来自画面左侧的窗边柔和侧光、阴天正面柔光、日落边缘轮廓光
- [背景描述]：例如室内米色墙面和挂画、夜晚街道橱窗灯虚化、绿色公园植被
- [姿态/构图描述]：例如平视半身人像、轻微三分之四侧头头像、表情自然的近距离特写

## 如果用户要求更明显的美化

保持身份约束完全不变，只把“允许的清理范围”扩展为：
`允许轻微淡化黑眼圈、轻微优化皮肤纹理、克制地清理色彩问题，同时保留毛孔和真实面部结构。`
